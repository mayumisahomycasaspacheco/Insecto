# Insecto
 
Insecto is a simple console-based insect classification system made in C++.

![Insecto](https://cdn.hackclub.com/01a0ef63-0f9f-78a9-b94a-3e9b1b5ae82f/captura_de_pantalla_2026-09-29_175257.png)
 
## What does it do?
 
Insecto lets you explore two kinds of insects from a single console program: butterflies and beetles. Both inherit from a base `Insecto` class that stores their scientific name, number of legs and color, while each one adds its own details — wingspan and feeding type for butterflies, family and flight ability for beetles.
 
## How to use it?
 
1. Go to the Releases section of this repository.
2. Download the .exe file.
3. Open the program.

That's it. Pick an option from the menu and see the data.
